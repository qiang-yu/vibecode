# --- Defence "remove_trigger_words" sanitize mode ---
# Used only when DEFENCE_REMOVE_TRIGGER_WORDS_SANITIZE / DEFENCE_SAFE_REMOVE_TRIGGER_WORDS_SANITIZE
# is true (both default to true). The sanitize step keeps a matched trigger span's data (URLs,
# emails, names, places, phone numbers, ...) and drops only the command words, so a following
# genuine tool call does not lose its arguments. If these are missing the server still runs: it
# logs once and falls back to deleting the span (the " (nothing) " placeholder).
spacy==3.8.16
nltk==3.10.3

# --- Extra data the two libs above need (NOT installed by pip, download separately) ---
#
# 1) spaCy English model en_core_web_sm (~12 MB), for POS tagging + named-entity recognition:
#        python -m spacy download en_core_web_sm
#
# 2) nltk WordNet corpora, for the verb filter that catches command words the POS tagger
#    mislabels on keyword fragments (e.g. "Concatenate"):
#        python -c "import nltk; nltk.download('wordnet'); nltk.download('omw-1.4')"
#    Behind a proxy, nltk >= 3.9 blocks proxied fetches (SSRF guard). If the proxy is trusted:
#        export NLTK_ALLOW_PROXIED_URLOPEN=1
#    then rerun the download. Data lands in ~/nltk_data/corpora/ (a path nltk searches by
#    default); the vllm-server process must be able to read it at runtime.
#
# Quick check that both extras are in place:
#   python -c "import spacy; spacy.load('en_core_web_sm'); from nltk.corpus import wordnet as wn; print(wn.synsets('concatenate', pos=wn.VERB)); print('ok')"
